# Repository instructions

Use the public DSH plugin APIs. Never patch DSH or test against a user's live profile. Keep original LICENSE/NOTICE and record provenance. Use Node.js 24, npm run setup, bridge test:prepare and npm run check. For bridge changes also run integration and packed delivery checks. Keep unit, fixture, deployment and device evidence distinct. Never commit signing, pairing, runtime state, private screenshots or credentials. Public release authors use their configured human Git identity.
