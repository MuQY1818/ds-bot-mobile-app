## 电脑配对管理

在 DSH 插件管理器分别安装并启用 `ds-bot-mobile-app` 与 `ds-bot-mobile-bridge`。配置好 Bridge 的独立状态目录和 HTTPS 后，打开账户菜单 **手机访问 → App**，生成二维码，并在手机发起请求后批准对应设备。官方 bundle 配置页可打开同一弹窗；第三方市场无需替本插件呈现配置页。配置步骤见[安装指南](installation.md)。

配套插件只负责界面。停用它会清理页面内二维码和进行中的请求，Bridge 与授权存储独立保留。缺少或未配置 Bridge 时，配套页面显示安装与配置提示。所有者接口仍可独立使用，见[Bridge 接口指南](bridge.md)。

网页“手机访问”的二维码属于 **DSH 浏览器登录**，与 App 的 **设备配对 JSON/二维码**不同。App 不能直接扫描 Web 登录链接完成配对。

## 验证范围

已执行的自动化与设备检查见[验证说明](validation.md)。源码检查、隔离宿主、打包生命周期和设备检查分别记录；Web 预览和 iPhone 示例截图均不能代替真实主机端到端验收。

本次只读部署复核确认：标准 Bridge 启用、HTTPS discovery 可达、文字发送能力声明存在，已有设备授权保留。未向用户的真实会话发送测试消息。

2026-10-18 的三张 iPhone 图片来自独立 staging 中的示例界面，组件与公开 `0.1.3` 相同，不读取生产主机。现有 App 已完成 USB 覆盖更新、缓存与会话索引保留核对，以及 XCUITest 设置导航。手机公网实际连接验收仍在进行，当前不声明已连通。
