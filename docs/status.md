# 当前状态

更新日期：2026-10-19。当前主要使用入口和开发重点是 [Mobile Web](https://github.com/MuQY1818/ds-bot-mobile-web)。原生 App 保留源码预览，本地设备更新与公开发行分别标注。

## 源码与安装版本

| 组件 | 当前版本 | 状态 |
| --- | --- | --- |
| 原生 App | `0.1.7`，源码预览 `0.1.7-preview.1` | 本地 iPhone build `11` 已安装并启动；没有公开 IPA/APK |
| 电脑配套插件 | `0.2.0` | 手机访问 App 标签、配对批准和设备管理 |

现有 App 包含点击即显示发送中气泡、保留下一条草稿、最新消息进入、近期前台连接复用和圆形回到底部按钮。更新沿用原应用与配对身份。

`0.1.5` 改善键盘展开、收起时输入区的贴合与底部间距，拖动消息完整收起键盘。现有设备已完成覆盖安装与启动；本轮真机自动交互检查因系统自动化模式初始化超时未完成，键盘交互证据仍以模拟器记录为准。

`0.1.6` 增加 iOS 原生局部选字、拖动手柄和系统复制菜单，将整条消息操作移到独立的 **⋯** 按钮。干净原生 Release 模拟器通过首次长按、真实手柄拖动及复制结果、另一段文字单击清选区、链接与长文代码检查，另通过 375pt 窄屏抽查。已同身份覆盖安装到本地 iPhone，更新前后的 26 条缓存键和值完全一致，启动成功；真机选字交互尚未单独验收。

`0.1.7` 修复中文标点边界导致的加粗星号残留，并将快捷复制和更多操作放到气泡下方，不再占用正文右侧宽度。375pt 模拟器实际消息组件验证了加粗、局部选字、原始 Markdown 复制和操作菜单；助手、用户与群聊布局分别检查。本地 iPhone 已更新到 build `11` 并启动，26 条原缓存键和值保留；本轮未自动验证真机完整交互。

## 已有验证与限制

本地 iPhone 已检查覆盖更新、现有配对在线读取、部分滚动和键盘交互。发送中反馈、迟到回执、失败保留和重试使用隔离环境验证。没有向用户生产会话发送测试消息。

当前独立 Bridge 支持 Bot / 群文字历史、完整消息和稳定回执，以及按宿主能力开放的模型、用量、记忆、日程和队列操作。不提供逐 token 增量、原生工具审批、媒体/语音、系统推送或群管理。
