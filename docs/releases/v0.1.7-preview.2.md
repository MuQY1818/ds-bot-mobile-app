# 0.1.7-preview.2

电脑端只需两个插件：原 Mobile Bridge 并入 **App 插件 0.3.0**，并直接适配官方 npm DS Bot `0.2.6`，不再需要 `ds-bot-0.1.7-codex.1.tgz` 兼容包。

## 变化

- `ds-bot-mobile-app` 0.3.0 同时提供配对与设备管理界面、设备认证、HTTP/WS 文字传输和所有者操作通道。`ds-bot-mobile-bridge` 不再单独发布。
- 会话校验走 DS Bot 公开的 `state`；脱敏沿用 DS Bot 自己的已知值规则（读取 `dsBotHome/secrets.json`）；消息通过宿主 `sessionController` 投递，手机的请求 ID 原样写入聊天记录，回执与历史一致。会话只读时拒绝发送。
- 新增可选配置 `dsBotHome`（默认 `DSH_HOME/bot`）。最低要求 DSH `0.2.1-rc.5`。
- 原生 App 仍为 `0.1.7`，无需更新。

## 从旧版迁移

1. 停用 `ds-bot-mobile-bridge`。
2. 把 profile `cordis.patch.yml` 中 `- id: ds-bot-mobile-bridge` 的整段配置原样改到 `- id: ds-bot-mobile-app` 下，**`home` 保持原路径**。
3. 安装并启用 `ds-bot-mobile-app-0.3.0.tgz`，再移除旧 Bridge 包。DS Bot 换成官方 npm `0.2.6`。

已配对的手机不需要重新扫码。不要让旧 Bridge 与新插件同时使用同一端口或 `home`。

## 验证

原生 App 154、SDK 30、App 插件 65 项测试通过；真实 DSH `0.2.1-rc.5` + 未修改的官方 DS Bot `0.2.6` 下 17 项 HTTP/WebSocket/SDK 集成断言（含稳定回执写入真实历史）与 6 项安装包生命周期断言通过；源码审计 0 发现。已在实际宿主完成迁移，原 iPhone 配对保留。

已知限制：Bot 的连接能力刚修改时，新配置在下一次电脑端发送或新会话时生效。
