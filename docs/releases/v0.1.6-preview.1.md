# 0.1.6-preview.1

原生 App `0.1.6` 为 iOS 消息正文增加系统文本选择：长按选中局部文字，拖动两端手柄调整范围，复制所选内容。消息操作移到独立按钮，继续提供整条复制、分享、回复和朗读。

保留 Markdown 字体样式、代码块复制、表格、链接与 Bot 引用。选择范围位于一个 Markdown 段落、代码块或表格单元内；跨段整条复制使用消息操作。正文只读，选择时不弹出输入键盘。

这次包含新的本地 iOS 原生模块，需要重新编译 App。电脑配套插件仍为 `0.2.0`，Mobile Bridge 仍为 `0.0.6`。模拟器、设备安装与尚未覆盖的范围分别记录于验证文档；没有公开签名 IPA/APK。

原生 Release 模拟器首次长按、真实手柄拖动、局部复制变化、点击另一段文字清选区、链接、长文与代码检查通过，另通过 375pt 窄屏抽查。本地 iPhone 已覆盖更新到 `0.1.6` build `10` 并启动，26 条缓存记录的键和值保留。真机选字交互尚未单独验收。
