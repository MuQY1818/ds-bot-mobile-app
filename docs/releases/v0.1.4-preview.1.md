# 0.1.4-preview.1

原生 App `0.1.4` 源码预览，电脑配套插件 `0.2.0`、Mobile Bridge `0.0.6`。

## 变化

- 点发送立即显示“正在发送”气泡，输入框清空后可以继续写下一条草稿；宿主确认后才视为成功。
- 未确认或失败的发送保留原内容，供查询与手动处理，迟到回执不会清掉新草稿。
- 进入会话直接显示最新消息，改善底部滚动，增加圆形返回最新消息按钮。
- 近期前台会话短时复用连接，历史和实时连接并行启动。

## 使用

本次仍提供源码与电脑插件，没有可直接安装的 IPA/APK。原生客户端需自行构建；电脑插件按[安装指南](../installation.md)安装并配对。希望直接在手机使用，建议选择 [Mobile Web](https://github.com/MuQY1818/ds-bot-mobile-web)。

已有本地 iPhone 保留稳定 build `8`。正文原生选择手柄候选未交付；完整设备矩阵及 Android 真机仍待完善。详见[当前状态](../status.md)。

## English

Native App `0.1.4` source preview, companion `0.2.0`, Bridge `0.0.6`. Sending immediately creates a “Sending…” bubble while preserving the next draft. Failed or uncertain requests remain recoverable. Chats open at the latest message, offer a round return button and reuse recent foreground connections.

Public IPA/APK files are not provided. Build the client yourself and follow the installation guide for computer plugins and pairing, or use Mobile Web for direct browser access. The existing local iPhone stays on build `8`; experimental selection handles and the full device/Android matrix are not delivered features.
