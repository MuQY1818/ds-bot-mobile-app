# 0.1.5-preview.1

原生 App 0.1.5 改善键盘展开与收起时的输入区过渡，修复顶部安全区被重复补偿造成的额外间距。输入区直接跟随原生键盘进度；拖动消息完整收起键盘。

保留反转消息列表、历史锚定与即时发送逻辑。电脑配套插件仍为 0.2.0，Mobile Bridge 仍为 0.0.6。
