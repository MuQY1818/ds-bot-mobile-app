# 兼容范围与验证

目标：公开 DSH 0.2.1-rc.2、Expo 54、React Native 0.81.5、Node.js 24。App 当前为源码预览，不等同 App Store / Play Store 发行。

原开发工作区已通过 118 App 测试、28 SDK 测试、30 Bridge 单元测试、17 HTTP/WebSocket/SDK 场景和 11 打包生命周期断言。桌面兼容包通过 635 单元测试及 41 mock smoke 步骤。公开导出新增独立依赖、通用签名脚本和 CI，必须以本仓库实际检查结果为准。

| 能力 | 当前 Bridge |
| --- | --- |
| Bot / 群文字 history/send | 支持；隐藏群成员 Session 不作为独立目标 |
| 推送 | 完整消息提交事件，断线恢复后有界合并 |
| 模型与状态 | 模型、effort、pin/hide |
| 记忆 | own 查看/遗忘；team 编辑与摘要关闭 |
| Usage | 宿主真实九列记录与可见 owner 映射 |
| 日程 | 创建、查看、删除；不支持修改 |
| 排队 | user-only 查看/移除；不承诺宿主跨重启 pending 恢复 |
| 逐 token、原生审批、媒体/语音、APNs、群管理 | 不支持 |

电脑端部署曾确认 8 Bot、1 群和设备配对身份保留，正常重启、HTTPS 入口以及原生多面板/webview 正常；这是本地配置证据，不代表新用户安装或完整设备验收。2026-10-18 的 iPhone 安装、数据保留与界面检查见下文；键盘、锁屏、网络切换和通知仍需分别验收。

DSH 的 pending inbox 重启恢复与 producer 授权仍有上游限制，不靠捕获全局按键、重发或修改核心掩盖。生产更新前应保持任务空闲并检查排队状态。

## App 电脑端配套插件

`companion/` 的单元检查覆盖配对响应晚到、页面关闭和卸载清理、二维码过期、显式批准、二次确认撤销、同源所有者通道、缺 Bridge 提示，以及慢于轮询间隔的状态请求。状态请求使用 single-flight；操作完成后重新获取状态，旧请求不能覆盖新操作的结果。

0.1.1 增加公开 `settings.section` 的“移动设备”入口，同时保留 bundle 配置页。每次挂载创建独立 controller；两个页面同时存在时，关闭其中一个不会中止另一页的请求或清除另一页的二维码。插件卸载仍会统一释放所有尚在使用的 controller。两个入口使用相同的 owner carrier，权限范围不变。

打包生命周期检查独立于浏览器交互验收，使用公开 DSH `0.2.1-rc.2`、已审查 DS Bot fixture 和 mock 模型。它验证官方管理器安装精确 `.tgz`、App 插件独立启停和移除、缺 Bridge 时的设置状态，以及 Bridge 服务器身份和设备授权保留。包管理器要求宿主重启时，测试在受控重启后核对最终状态；不会把网络请求中断当作插件安装成功。

实际浏览器交互已在隔离宿主中验证配对二维码与手动 JSON、手机 SDK 请求、电脑批准、会话读取、二次确认撤销及撤销后旧 access token 被拒绝。此处的“手机”是合成 SDK 测试设备，不能代替 iOS / Android 真机扫码、相机权限和安全存储验收。

## 0.2.0 统一访问入口

App 配套插件与 Web 0.4.0 通过共同的页面级 provider 协议共享唯一菜单和弹窗，Bridge 认证接口未变。新增 9 项 registry 检查覆盖单插件、双插件、leader 接管、当前模式停用、同 ID 替换、最后卸载与不缓存凭据；配套插件共 18 项检查通过。

隔离的真实 DS Bot / DSH 页面已验证两个标签、只启用 App、只启用 Web、重新双启用仍为一个弹窗；Web/App 切换清理上一模式二维码。键盘切换、Esc 和焦点恢复可用。390px 竖屏、844×390 横屏与1440px桌面无页面横向溢出。以上使用合成设备，不能代替手机真机验收。
