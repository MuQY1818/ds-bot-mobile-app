# 常见问题

## 我应该用 Web 还是 App？

想直接在手机上使用，优先选择 [Mobile Web](https://github.com/MuQY1818/ds-bot-mobile-web)。原生 App 当前需要自行构建，更适合具备平台工具链的开发者。两者连接同一支团队，不需要复制 Bot。

## 为什么 Release 中的 tgz 不能装到 iPhone？

这些是电脑端 DSH 插件包。手机原生客户端尚无公开可直接安装的 IPA/APK，需要按[安装指南](installation.md)自行构建。Web 用户无需构建 App。

## 两个电脑插件分别做什么？

`ds-bot-mobile-app` 提供配对和设备管理界面；`ds-bot-mobile-bridge` 负责设备认证与消息传输。停用配对界面不会停止 Bridge，也不会撤销手机。

## Web 登录二维码能给 App 扫吗？

不能。Web 码用于浏览器登录；App 码用于发起设备配对，随后需要电脑批准。请在手机访问弹窗选对标签。

## 支持所有原版功能吗？

不支持。当前独立 Bridge 主要提供文字历史、完整消息、稳定发送回执及部分宿主管理操作；逐 token、原生审批、媒体/语音、系统推送和群管理尚未提供。

## 正在发送的气泡是否表示已经成功？

不是。它表示客户端已接受本次操作。只有宿主确认后才视为已发送；未知或失败的请求会保留原内容，供检查和手动处理。

## 能离线工作吗？

可查看已有缓存和编辑草稿，但收发需要电脑、Bridge 和网络可用。恢复网络不会自动发出草稿。

## 长按文字的光标和选择手柄已经做好了吗？

当前 `0.1.7` 保留自 `0.1.6` 引入的 iOS 系统局部文字选择和拖动手柄；气泡下方的复制按钮复制原始 Markdown，**⋯** 打开整条消息操作。该功能需要重新编译原生 App，不能通过刷新旧版获得。模拟器验证和本地手机安装状态分别记录在[状态页](status.md)。

## Android 已经完整验证了吗？

没有。源码面向 iOS / Android，但 Android 真机与完整设备矩阵仍待完成。已完成的本地 iPhone 检查不能直接推广到其他设备。
