# 原生 App 使用指南

本页描述原生 App 的基本操作。当前源码预览为 `0.1.7-preview.1`；设备安装与验证进度见[当前状态](status.md)。如果希望直接从浏览器使用，选择 [Mobile Web](https://github.com/MuQY1818/ds-bot-mobile-web)。

## 会话与历史

连接后打开现有 Bot 或群聊，复用电脑团队。显式进入会话从最新消息开始；阅读历史时可使用圆形向下按钮回到最新位置。从详情页返回时保留阅读位置。

近期会话在前台短时保留连接，历史读取和实时连接并行进行。进入后台、退出登录或更换主机时会释放连接。缓存内容可供查看，但不代表电脑当前在线。

## 发送状态

点发送后，文字立即移到“正在发送”气泡，输入框清空，可继续编辑下一条草稿。只有宿主确认后才视为已发送。

结果未知或失败时，原内容和请求会保留。使用界面提供的检查或重试操作，先查询原发送状态；不要为同一条内容反复创建新发送。旧回执不会清掉正在编辑的新草稿。

当前独立 Bridge 推送完整回复，不是逐 token 增量。语音、媒体、原生审批及通知能力尚未提供；可用项目以宿主声明为准。

## 网络和草稿

电脑与 Bridge 需要保持运行。使用 Tailscale 时，两端都需连接对应私网。离线时可查看已有缓存和草稿，恢复连接不会自动替用户发送草稿。

如果主机身份发生变化，按界面提示重新核对和配对。不要仅因为连接恢复慢就删除 App 或 Bridge 状态目录。

## 配对与设备管理

电脑选择 **手机访问 → App**，查看待批准请求和已授权设备。要断开某台手机，选择“撤销访问”并确认。停用配对管理界面不会撤销已有设备。

配对码只给自己的设备。隐藏二维码会清理页面内容，但不代表撤销已经发出的配对请求或已批准设备。

## 文字选择与当前边界

当前 `0.1.7` 保留自 `0.1.6` 引入的 iOS 原生文本选择：长按正文选择局部文字，再拖动两端手柄调整范围，使用系统菜单复制。正文只读，选择时不弹出键盘。该能力需要包含本地文本选择模块的原生构建，Expo Go 不可用；实际交互验证与设备安装进度以状态页为准。

选择范围位于一个 Markdown 段落、代码块或表格单元内。气泡下方的复制按钮可直接复制完整消息；**⋯** 菜单提供分享、回复和朗读。完整消息复制保留原始 Markdown，局部选字复制的是所选文字。链接仍可直接轻点打开。

中文标点旁的加粗（如 `**说明：**内容`）会正确显示，代码或转义后的星号继续按原文保留。
