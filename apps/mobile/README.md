# DS Bot Mobile App client

Expo 54 / React Native 0.81 client. See the repository [installation guide](../../docs/installation.md), [development guide](../../docs/development.md) and [compatibility record](../../docs/validation.md).

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm start
```

Native builds use your own signing identity. Never commit credentials or reuse another project's signing key. The current standalone bridge supports a restricted capability set; the root README describes the supported behavior. Inherited UI components do not imply server support.
